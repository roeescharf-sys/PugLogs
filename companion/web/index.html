Welcome to PugLogs

PugLogs reads your applicants' runs from Warcraft Logs, which needs a free API client of your own (it takes a minute, and it stays on this computer).

  1. Log in at warcraftlogs.com and open API Clients → Create Client.
  2. Name: PugLogs · Redirect URL: type http://localhost (the form requires one; it isn't used) · leave "Public Client" unchecked · Create.
  3. Copy the two values it shows into the boxes below.
